智跑慧巡平台 同伴电脑使用说明
================================

一、收到压缩包以后

1. 将整个压缩包解压到空间充足的磁盘。
2. 建议路径简单一些，例如：D:\marathon-monitor
3. 不要在压缩包内部直接运行，也不要只复制其中某一个文件夹。
4. 完整解压后，项目约占 16 GB；首次解压可能需要较长时间。

二、直接启动

1. 双击“同伴电脑_一键启动.bat”。
2. 系统会打开两个 PowerShell 窗口，分别运行后端和前端。
3. 大约 10 秒后，浏览器会自动打开：http://127.0.0.1:5173/
4. 第一次显示校园三维模型可能较慢，等待建筑加载完成即可。
5. 使用过程中不要关闭两个 PowerShell 窗口；演示结束后直接关闭它们。

这个完整包已经自带 Python、Node.js、后端依赖、前端依赖和校园三维模型。
同伴不需要再次运行 npm install 或 pip install。

三、使用 VS Code 修改

1. 打开 VS Code。
2. 选择“文件”→“打开文件夹”。
3. 选择解压后的整个项目文件夹，不要只打开 frontend 或 backend。
4. 前端页面主要在 frontend\src 中修改。
5. 后端接口和模拟逻辑主要在 backend\app 中修改。
6. 修改前先与组员确认分工，避免两个人同时覆盖同一个文件。

四、常用地址

平台首页：http://127.0.0.1:5173/
后端接口文档：http://127.0.0.1:8000/docs
后端健康检查：http://127.0.0.1:8000/api/health

五、打不开时先检查

1. 压缩包是否完整解压。
2. 两个 PowerShell 窗口是否仍在运行。
3. 5173 或 8000 端口是否被其他程序占用。
4. Windows 防火墙询问时，允许在专用网络中访问。
5. 如果出现红色错误，把两个 PowerShell 窗口完整截图发给项目负责人。

六、数据说明

校园三维模型是真实场景模型资源；手环、无人机观测、环境、报警和风险数据为比赛演示使用的模拟数据。
校园示范环线用于平台流程展示，不等同于完整 42.195 km 实测马拉松赛道。
