# 校园路线由同伴绘制、平台导入的交接说明

旧版依据截图目视拟合的校园候选线位存在道路偏差，已停止展示。团队后来提交的 `marathon_route.geojson` 含有跨建筑、跨林地的长直线，因此也没有直接作为正式路线使用。平台现内置一条依据现有倾斜摄影模型**可见道路人工取点**的约 1.794 km 闭合演示线，文件为 `data/nanlin_road_loop_model_traced.geojson`。它仅用于演示，仍须测绘/GIS 同伴及现场人员核查道路通行、坐标和安全条件。**模型上看起来贴路、导入成功，都不等于完成实测或校方审批。**

这条演示线的第三列是模型显示高度：大部分由当前模型表面取样，树冠等遮挡处按邻近道路高度平滑。平台会将线条再抬高约 2 m，避免被三维瓦片遮住。这些数值不是测绘高程成果，也不应直接套用到其他校园模型。其他电脑同步仓库里的演示路线文件后会自动看到这条线；如果重新导入路线，导入结果会优先于内置演示线。

## 同伴在 QGIS 中做什么

1. 先准备有坐标的校园正射影像、可靠道路底图或经校核的测绘资料。普通截图没有地理坐标，不能直接当作精确底图描线。若只有倾斜摄影 OSGB 模型，先由 GIS/建模负责人确定可用于配准或量测的底图与坐标关系。
2. 建立**线图层**，沿实际可通行的道路中心或约定行进侧绘制路线。可以画一条完整线路，也可以分段画多条。若要让路线承载平台模拟数据，应分为五条连续线，并依次填写 `segment_id` 为 `S1`、`S2`、`S3`、`S4`、`S5`，同时填写 `name`（赛段名称）和 `task`（监测说明）。不要把路线画到建筑、绿地、围栏或模型外缘。
3. 如需保障点，另建**点图层**，标明起终点、医疗点、补给点和观察点。推荐字段为 `site_id`、`kind`、`name`、`note`；`kind` 可填 `start`、`medical`、`water`、`marshal`，也可填“起终点”“医疗”“补给”“观察”。点位须由保障负责人确认。
4. 对两张图层分别右键选择“导出 → 另存为…”，格式选 **GeoJSON**，导出坐标参考系选 **WGS84 / EPSG:4326**。路线和点位各交一个 `.geojson` 文件。GeoJSON 坐标顺序应为 `[经度, 纬度]`；校园场景附近大致为经度 118.8、纬度 32.08。

QGIS 可以在“另存为”时选择输出坐标系，不要求原始测绘图层必须先改为 EPSG:4326。若图层本身没有正确的原始坐标系，单纯改变导出选项不能修复错误位置。

## 平台负责人怎么导入

1. 启动平台前后端，进入监控看板，切换到“校园实景”。
2. 点击地图上方“导入路线”；先选择路线 GeoJSON，再按需要选择保障点 GeoJSON。
3. 平台会检查文件格式、几何类型、坐标范围与重复编号。成功后显示路线段数、点位数和折线长度；刷新页面后仍会读取保存在本机项目中的导入结果。
4. 在三维模型中逐段目视核查是否贴合道路，记录任何偏移，交回 GIS 同伴修订原始图层后重新导出、重新导入。平台显示长度只是坐标折线长度，不是现场测量里程。

导入后的规范化文件保存在项目的 `data/campus_route_import.json`。若要让其他电脑看到**重新导入后的同一条路线**，团队需将该文件加入 Git 仓库并同步；网页上传不会自动发布到 GitHub。内置演示线的源文件 `data/nanlin_road_loop_model_traced.geojson` 则随代码同步。校园建筑模型另存于 `frontend/public/3dtiles/nanlin`，体量较大且不随路线文件一起上传，其他电脑还需单独部署模型文件。

## 当前边界

- 平台只接受 GeoJSON 的路线 `LineString` / `MultiLineString` 和点位 `Point`，每类单独导入；不接受 QGIS 工程文件、截图、原始 OSGB 或 `.zip` 直接充当路线。
- 内置校园环线已分为 S1–S5。切换到校园实景后，平台按模拟运动员在逻辑赛段内的完成比例，将运动员、无人机、报警和专题风险投影到对应校园道路段。这里连接的是“赛段编号与流程比例”，不是把 1.794 km 伪装成 42.195 km，也不是实测定位。
- 外部导入路线只有在恰好包含 S1–S5 五个不同编号时才会自动建立上述映射；编号缺失、重复或使用 C1 等其他编号时，只显示路线本身。
- 普通二维路线会尝试贴到当前三维瓦片或地球表面；内置演示线使用模型表面取点高度。复杂遮挡处仍需人工检查，不能以页面视觉效果代替道路测绘。

QGIS 官方参考：[创建图层](https://docs.qgis.org/3.44/en/docs/user_manual/managing_data_source/create_layers.html)、[导出时更换坐标系](https://docs.qgis.org/3.44/en/docs/training_manual/vector_analysis/reproject_transform.html)。
