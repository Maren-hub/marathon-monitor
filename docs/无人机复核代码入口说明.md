# 无人机复核代码入口（原型）

## 如何打开

启动前后端，进入监控平台。在“实时事件”中先用底部按钮模拟一条聚集或跌倒事件，再点击该事件的“无人机复核”。平台会记录一次**模拟的无人机处置动作**，然后打开“无人机动态监测”资料页。没有报警时，也可点击“实时事件”右上角的“监测代码 ↗”，或直接访问 `http://127.0.0.1:5173/#uav-review`。

资料页收录了用户提供的 `E:\marathon_detect.rar` 中的七个 Python 源码文件和较短的 `videos/drone3.mp4` 示例片段，保存在 `frontend/public/uav-review/marathon_detect/`。这些小文件可随项目仓库一起交给同伴；原始压缩包、其他三个大视频和 YOLO 权重**没有**复制进平台，也没有上传 GitHub。

## 目前做到了什么

- 点击“无人机复核”后可查看对应事件信息、播放示例视频、逐个阅读或下载源码。
- 原版 `main.py` 是桌面 OpenCV 程序：读取本地视频，调用 `yolo_pose.py`，再用 `cv2.imshow` 弹出结果窗口。它不是可以直接跳转的网页。
- **尚未**把 YOLO 推理结果接入平台告警，网页中的视频也不是该事件的实时无人机画面；演示和比赛说明中应明确称为“代码与素材接入原型”。

## 后续若要实现真正的网页识别

由负责视觉算法的同伴确认模型权重、运行依赖、阈值和样本使用权限；把检测程序封装成读取视频/视频流并输出结构化结果的服务接口，例如时间、赛段、目标框、置信度与疑似跌倒标记。平台再接收这些结果，关联事件和地图位置。不能仅把 `.rar` 或 `.py` 文件挂成链接就宣称完成实时监测。
