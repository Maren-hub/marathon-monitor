智跑慧巡平台 同伴电脑使用说明
================================

1. 将整个压缩包完整解压到空间充足的磁盘，不要在压缩包内部直接运行。
2. 建议解压到简单路径，例如 D:\marathon-monitor。
3. 双击 START_PLATFORM.bat。
4. 保持随后出现的两个 PowerShell 窗口开启。
5. 浏览器将自动打开 http://127.0.0.1:5173/。

完整包已包含 Python、Node.js、前后端依赖和校园三维模型，不需要再次运行 npm install 或 pip install。

如果要使用 VS Code 修改：

1. 在 VS Code 中选择“文件”→“打开文件夹”。
2. 选择解压后的整个 marathon monitor 文件夹。
3. 前端代码位于 frontend\src。
4. 后端代码位于 backend\app。
5. 修改前先与组员确认分工，避免覆盖同一个文件。

常用地址：

平台首页：http://127.0.0.1:5173/
后端接口文档：http://127.0.0.1:8000/docs
后端健康检查：http://127.0.0.1:8000/api/health

打不开时请检查：

1. 是否已经完整解压。
2. 两个 PowerShell 窗口是否仍在运行。
3. 5173 或 8000 端口是否被其他程序占用。
4. Windows 防火墙询问时，允许在专用网络中访问。
5. 将 PowerShell 中的红色错误完整截图发给项目负责人。

数据说明：校园三维模型是真实场景模型资源；手环、无人机观测、环境、报警和风险数据为比赛演示使用的模拟数据。
